# Contributing

Thank you for wanting to contribute.

To help out you can:

- open new issues about your ideas for making this project better
- get involved in any open issue or pull request
- improve the documentation
- add new tests

## Code contributing

### Lint code

We use oxlint to lint and format code automatically.

### Run tests

Run the tests using `pnpm test`

### Type-check and build

Run `pnpm typecheck` to check the TypeScript sources and `pnpm build` to generate the package files in `dist/`.
